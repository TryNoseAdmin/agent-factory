# Universal Rules Index

Cross-project non-negotiables. Established through real production incidents.

- **[Never commit directly to main](never-commit-main.md)** — Always feature branch + PR.
- **[Review before merge](review-before-merge.md)** — "Ship it" does NOT skip review.
- **[No fabricated external claims](no-fabricated-claims.md)** — Cite or mark `[UNVERIFIED]`.
- **[Fail loud over silent hallucination](fail-loud.md)** — No offline fallbacks for grounded calls.
- **[Prefer automation over manual exploration](prefer-automation.md)** — Use MCP tools, hooks, scripts first.
