## How to Use

### `/nose-content` — Activate the agent

Simply invoke the skill. The agent will:
1. Read its state (`.agents/content-state.json`)
2. Assess the current situation
3. Diagnose what needs to happen
4. Execute the highest-priority work
5. Report back with a weekly standup
6. Update state for next session

**You do not need to tell it what to do.** The agent figures it out.

### `/nose-content status` — Quick check

Returns the current state summary without running the full agent.

### `/nose-content report` — Force a standup

Triggers the report phase only. Agent reads state and outputs the weekly standup without executing new work.

## What the Agent Does

The Content Strategist is an autonomous employee with full decision authority on:
- Content strategy and calendar
- Channel selection and prioritization
- Lead magnet creation
- Community growth tactics
- Funnel design (awareness → signup)
- Brand voice enforcement
- Experiment design and execution

It follows the **14 Iron Laws** derived from high-ticket funnel analysis, adapted for NOSE's perfume discovery context.

### The Autonomy Loop

```
ASSESS → DIAGNOSE → PLAN → EXECUTE → REPORT → UPDATE STATE
```

**Assess:** Reads `.agents/content-state.json` and `.agents/nose-state.json`
**Diagnose:** Identifies the highest-leverage bottleneck
**Plan:** Picks ONE initiative to execute
**Execute:** Generates actual content, strategies, and plans
**Report:** Outputs weekly standup format
**Update State:** Writes back to `.agents/content-state.json`

## Brand Guardrails (Enforced by Agent)

### Golden Rule: POSITIVE-ONLY POSITIONING
- Never mention Fragrantica, Parfumo, Basenotes, or any competitor by name
- Never use phrases like "unlike other platforms", "better than", "competitors lack"
- Only highlight what NOSE does well — let the quality speak for itself

### Content Pillars

All content maps to one of these 5 pillars:

| Pillar | Focus | Example Topics |
|--------|-------|----------------|
| **Discovery** | AI search, federated search, smart filters | "Find your signature scent in 30 seconds" |
| **Community** | Forums, SOTD, Trails, Lounges | "Join 500+ fragrance lovers sharing daily picks" |
| **Education** | Notes, accords, scent families, seasons | "What makes Oud so expensive? The note explained" |
| **Curation** | Collections, best-of lists, seasonal picks | "Top 10 monsoon fragrances under 2000" |
| **Identity** | Perfume Cards, profiles, scent journeys | "Your fragrance identity, visualized" |

### Tone Matrix

| Context | Tone | Example |
|---------|------|---------|
| Discovery features | Confident, inviting | "Your signature scent is one search away." |
| Community | Warm, inclusive | "Every nose tells a story. Share yours." |
| Education | Curious, accessible | "Ever wondered why oud costs more than gold?" |
| Announcements | Excited, grounded | "We just made finding your perfect perfume even easier." |
| SOTD | Personal, relatable | "Rainy Mumbai morning? This one hits different." |

### Do's
- Use "we" and "you" — personal, conversational
- Reference Indian cities, weather, festivals, occasions
- Include sensory language (not clinical chemistry)
- End with questions or CTAs that invite engagement
- Use numbers when impressive ("4,600+ perfumes", "AI-powered")

### Don'ts
- No competitor names or comparisons, ever
- No "best in the market" or "only platform that" claims
- No jargon: "vector embeddings", "RAG pipeline", "cosine similarity"
- No fake urgency: "Limited time!", "Don't miss out!"
- No generic influencer-speak: "obsessed", "game-changer", "literally dying"
- No emojis in blog content (social media: max 3 per post)

## Tactical Content Templates

When the agent generates individual content pieces, it uses these formats:

### Tweet / Thread
```
Hook: [curiosity gap or bold claim]
Body: [value or story]
CTA: [soft engagement question]
```

### Instagram Caption
```
Hook (first line): [scroll-stopper]
Body: [value or story, line breaks every 1–2 sentences]
CTA: [question or save prompt]
Hashtags: [20–25 tags, mix of broad and niche]
```

### Blog Post
```
H1: [SEO keyword-driven title]
Intro: [2–3 paragraphs, India context]
H2s: [structured sections]
H3s: [sub-sections]
CTA: [soft product mention at end]
Meta: [title + description]
```

### Newsletter
```
Subject: [curiosity or benefit]
Preview: [pre-header text]
Section 1: [value drop]
Section 2: [community highlight or story]
Section 3: [CTA]
```

### Reddit Post
```
Title: [value-first, question or guide format]
Body: [detailed, helpful, NOSE mention only at end]
```
